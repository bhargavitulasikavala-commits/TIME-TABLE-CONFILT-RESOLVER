# 🎓 EduTime - College Timetable & Conflict Resolver System

**EduTime** is a web-based timetable management and conflict resolution platform designed for educational institutions. It simplifies class scheduling, prevents faculty and room double-booking, and provides an interactive master timetable view.

---

## 📌 Project Features

* **Smart Conflict Resolution:** Automatically detects scheduling overlaps (double-booking of faculty or classrooms) and prompts modal alerts to resolve conflicts.
* **Interactive Dashboard:** Live metrics tracking Total Subjects, Total Faculty, Scheduled Classes, and Resolved Conflicts.
* **Class Scheduler:** Easily schedule classes by specifying Subject, Department (CSE, ECE, IT), Semester, Section, Faculty, Room, Day, and Time Slot.
* **Timetable Matrix:** Master timetable grid view with instant filtering by Department and Semester.
* **Export & Print Options:** Print the timetable directly or export it as a PDF document (`html2pdf.js`).
* **Faculty & Room Management:** Dynamic management tools to add new faculty members and room capacities.
* **Theme Customization:** Toggle between Light Mode and Dark Mode for user preference.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & Fonts:** Google Fonts (Inter), Font Awesome 6 Icons
* **Libraries:** `html2pdf.js` (for PDF generation)
