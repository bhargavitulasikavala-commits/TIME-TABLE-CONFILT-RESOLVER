# 🎓 EduTime: Smart College Timetable Resolver

**EduTime** is a simple and smart web application designed to help colleges create timetables effortlessly. It automatically detects and prevents scheduling conflicts (like double-booking a teacher or a classroom).

---

## ✨ Key Features

* 🚀 **Smart Conflict Detection:** Alerts you immediately if a faculty member or room is assigned to two classes at the same time.
* 📊 **Live Dashboard:** Keep track of total subjects, faculty, and scheduled classes in one place.
* 📅 **Easy Scheduler:** Add classes by selecting the Department, Semester, Faculty, Room, and Time slot.
* 🖨️ **Export to PDF:** Download your final master timetable as a PDF or print it directly.
* 🌙 **Dark & Light Mode:** Toggle between themes for a comfortable viewing experience.

---

## 💻 Technologies Used

* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **Libraries:** `html2pdf.js` (for downloading timetable as PDF)
* **Assets:** Google Fonts (Inter), FontAwesome 6 (Icons)
